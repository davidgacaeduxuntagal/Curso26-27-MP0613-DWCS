ADTs CON LA SPL: EL ARRAY DE TAMAÑO FIJO (SplFixedArray) IES de Rodeira

El array de tamaño fijo (Fixed-size array): SplFixedArray

Caso práctico

Carlos programa la venta de entradas del cine del pueblo. La sala tiene 8 filas de 12 butacas: ni una más ni una menos. Con un array normal, un error de cálculo ($sala[8][3]) crearía en silencio una fila 9 que no existe, y la sala "crecería". María le propone SplFixedArray: un array con un tamaño fijo que avisa si te sales de él y que, además, ocupa menos memoria.

1.- Qué es un array de tamaño fijo

Un array de tamaño fijo es la estructura más básica de la informática: N casillas numeradas de 0 a N-1, guardadas una detrás de otra. Se accede a cualquier casilla directamente por su número (O(1)).

Los arrays de PHP son mucho más flexibles: en realidad son tablas hash ordenadas que admiten claves de cualquier tipo, crecen solas y mantienen el orden de inserción. Esa flexibilidad tiene un coste en memoria y permite errores silenciosos. SplFixedArray es el array "clásico":

2.- La clase SplFixedArray

<?php
$semana = new SplFixedArray(7);       // 7 casillas, todas a null
$semana[0] = 14.5;
$semana[6] = 19.5;
echo $semana->getSize();              // 7 (también count($semana))
echo $semana[2] ?? 'sin dato';        // "sin dato"

$semana->setSize(10);                 // crecer: las nuevas valen null
$semana->setSize(3);                  // encoger: ¡se pierden los datos que sobran!

$array = $semana->toArray();          // a array normal, para usar array_sum, array_filter...
$fijo = SplFixedArray::fromArray([3 => 'c', 1 => 'a']);          // conserva las claves: [null, 'a', null, 'c']
$fijo = SplFixedArray::fromArray([3 => 'c', 1 => 'a'], false);   // sin conservarlas: ['c', 'a']
  • Índices: solo enteros (o textos numéricos como '3'). Una clave de texto como 'lunes' lanza TypeError; un índice fuera de rango (también los negativos), RuntimeException; y $a[] = $x, Error.
  • isset($a[$i]) no da error con índices fuera de rango: devuelve false.
  • foreach recorre las casillas en orden, con su índice.
  • fromArray() exige claves enteras no negativas (si no, InvalidArgumentException).
Debes conocer

$fijo[$i]++ no funciona. Los operadores que modifican "en el sitio" (++, --, +=, .=...) no tienen efecto en un SplFixedArray: PHP avisa con "Indirect modification of overloaded element of SplFixedArray has no effect" y el valor no cambia. Hay que leer y escribir por separado:

<?php
$histograma[$nota] = $histograma[$nota] + 1;     // bien
// $histograma[$nota]++;                         // mal: no suma nada

Lo mismo ocurre con $fijo[$i][] = $x si la casilla contiene un array (no un objeto): se modifica una copia.

3.- Matrices: SplFixedArray de SplFixedArray

Un tablero o una sala de cine es un SplFixedArray de filas, y cada fila otro SplFixedArray. Como las filas son objetos, $tablero[$f][$c] = 'X' sí funciona (se modifica el objeto de la fila):

<?php
$tablero = new SplFixedArray(3);
for ($f = 0; $f < 3; $f++) {
    $tablero[$f] = new SplFixedArray(3);
}
$tablero[1][1] = 'X';
$tablero[3][0] = 'O';                // RuntimeException: no hay fila 3

4.- ¿Cuándo usar SplFixedArray?

Usa SplFixedArray si...Usa un array normal si...
El número de elementos es fijo o se conoce de antemano (tableros, butacas, días, meses, notas de 0 a 10)El tamaño cambia continuamente (un carrito)
Las claves son posiciones 0..N-1Las claves son textos (datos de un cliente)
Hay muchísimos elementos y la memoria importa (lecturas de sensores)Necesitas muchas funciones array_*
Quieres que un índice erróneo dé un error, no un dato nuevoNecesitas añadir con $a[] = ...

6.- Ejercicio resuelto: buffer circular de un sensor

Ejercicio resuelto

Un sensor de calidad del aire envía una lectura por minuto. Hay que guardar solo las 5 últimas y calcular su media, sin mover datos de un sitio a otro.

<?php
final class BufferCircular
{
    private SplFixedArray $datos;
    private int $siguiente = 0;        // dónde se escribirá la próxima lectura
    private int $guardados = 0;

    public function __construct(int $capacidad)
    {
        $this->datos = new SplFixedArray($capacidad);
    }

    public function anadir(float $valor): void
    {
        $this->datos[$this->siguiente] = $valor;                                  // sobrescribe la más antigua
        $this->siguiente = ($this->siguiente + 1) % $this->datos->getSize();     // da la vuelta
        $this->guardados = min($this->guardados + 1, $this->datos->getSize());
    }

    public function media(): float
    {
        return round(array_sum(array_slice($this->datos->toArray(), 0, $this->guardados)) / $this->guardados, 1);
    }
}
$aire = new BufferCircular(5);
foreach ([42, 45, 51, 48, 60, 72, 68] as $lectura) {
    $aire->anadir($lectura);
}
echo $aire->media();               // 59.8 (media de 51, 48, 60, 72 y 68)

Observa que escribir siempre cuesta lo mismo (O(1)): no se desplaza ningún elemento, solo avanza la posición. Con un array y array_shift habría que renumerar todo en cada lectura.

Autoevaluación
  • ¿Qué valor tienen las casillas de un new SplFixedArray(5)? null.
  • ¿Qué ocurre con $fijo[5] = 1 si el tamaño es 5? RuntimeException: los índices van de 0 a 4.
  • ¿Por qué no funciona $contador[$i]++ en un SplFixedArray? Porque la modificación "indirecta" no se aplica; hay que escribir $contador[$i] = $contador[$i] + 1.
  • ¿Cómo usas array_sum con un SplFixedArray? Convirtiéndolo antes: array_sum($fijo->toArray()).
